02 Systems integration · Research workflow

Zotero ↔ NotebookLM

Built for Julia Turc, founder of Storia AI: a cross-app sync system that sends Zotero collections to NotebookLM and brings source guides, source content, and notes back into Zotero.

Architecture
Stateless polling bridge
Modes
Consumer bridge & Enterprise API
Output
Bidirectional research workflow
  • Collection sync with remote-first duplicate detection and binary PDF uploads
  • Reverse import of source guides, source content, and NotebookLM notes
  • Reverse-engineered NotebookLM’s undocumented RPC endpoints and payload formats
  • Authenticated browser bridge over a localhost task queue — without storing credentials
